# MockInterview

Copilote discret pour les entretiens, les levées de fonds et les négociations en visio.

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

Cette version simule le flux audio et le non-verbal. Le micro et la webcam ne sont pas utilisés. Le plan de démo et le quota mensuel restent dans le navigateur.
